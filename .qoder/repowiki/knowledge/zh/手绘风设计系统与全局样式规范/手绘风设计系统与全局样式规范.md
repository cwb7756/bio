本项目采用「手绘风」视觉风格，通过微信小程序原生 CSS + CSS 变量（Design Tokens）构建统一的设计系统，无第三方 UI 框架或样式预处理工具。核心约定如下：

1. 设计令牌集中管理
- 所有颜色、阴影、圆角、字体等 Design Token 在 `miniprogram/app.wxss` 顶部以 CSS 自定义属性形式声明，如 `--green`、`--paper`、`--sh`、`--r1` 等，页面级样式直接引用这些变量，保证全应用色彩与质感一致。
- 背景使用点状纹理 `.bg-dots` 营造纸张/笔记本氛围，配合 `var(--hl)` 荧光笔高亮效果强化“手写笔记”感。

2. 手绘组件基类
- 全局提供一套可复用的基础组件类：`.sketch`（手绘卡片）、`.card`（常规卡片）、`.btn` / `.btn.deep` / `.btn.ghost`（按钮三态）、`.chip`（标签）、`.segment`（分段控件）、`.search`（搜索框）、`.sec-title`（章节标题）、`.statusbar`、`.navbar`、`.action-bar`、`.page-container`、`.page-pad` 等，各页面通过组合这些类快速搭建界面，避免重复样式。

3. 图标系统：内联 SVG data URI
- 不使用外部图标库或图片资源，所有图标以 `<svg>` 源码经 `data:image/svg+xml,...` 编码后作为 `background-image` 注入到 `.icon-*` 类中，按功能域分组（导航、操作、角色、科学、菜单/成就、猫咪养成、登录专用），并通过 `stroke` 颜色区分默认/选中/白底等变体。
- 图标尺寸统一为 44rpx × 44rpx，通过 `.icon` 基类设置 `background-size: contain` 复用。

4. 悬浮玻璃质感 TabBar
- 自定义底部导航位于 `custom-tab-bar/index.wxss`，采用固定定位 + `backdrop-filter: blur(40rpx) saturate(180%)` 实现毛玻璃悬浮条，滑块使用弹性贝塞尔曲线过渡，选中态图标从灰色 `#98A29B` 切换为深绿 `#3D9970`。

5. 页面组织与响应式策略
- 每个页面目录包含 `.js/.json/.wxml/.wxss` 四件套，页面级样式仅覆盖局部布局；全局通用样式全部下沉至 `app.wxss`。
- 未使用媒体查询做断点适配，主要依赖 rpx 单位与 flex/grid 布局自适应不同屏幕宽度。
- 暂无 SCSS/Less/Tailwind 等预处理或原子化方案，也未发现 `components` 目录下的独立组件样式文件，当前处于轻量级单页样式阶段。

6. 开发者约定
- 新增颜色/阴影/圆角应优先扩展 `app.wxss` 中的 CSS 变量，而非硬编码色值。
- 新增图标应在 `app.wxss` 对应分组下追加 `.icon-*` 类，保持命名前缀一致。
- 新建页面时优先复用 `.sketch`、`.card`、`.btn`、`.segment` 等基类，减少手写边框/阴影/圆角的重复代码。
- 如需引入第三方 UI 组件库，请在对应页面的 `.json` 中通过 `usingComponents` 注册，并遵循现有手绘风配色与圆角规范。
