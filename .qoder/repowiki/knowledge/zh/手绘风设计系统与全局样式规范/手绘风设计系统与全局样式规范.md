## 1. 系统/方法概述
- 基于微信小程序原生 CSS（`.wxss`），采用 **CSS 自定义属性（变量）+ 全局基础组件类** 的设计系统，无 SCSS/Less/Tailwind 等预处理或原子化框架。
- 视觉风格为“手绘/手账”风：不规则圆角、粗描边、手绘阴影、点阵背景、高亮标记等，整体配色以绿色系为主，强调低对比、柔和的纸质质感。
- 图标体系完全内联 SVG data URI，按语义分类命名（导航、操作、角色、科学、成就、猫咪养成、登录专用），无需外部字体图标库。
- 底部 TabBar 使用 `custom: true` + 悬浮玻璃态容器，通过 `backdrop-filter` 实现毛玻璃效果，滑块带弹性动画。

## 2. 关键文件与包
- `miniprogram/app.wxss` — 全局设计令牌（颜色、阴影、字体、手绘圆角）、通用组件类（`.sketch` `.card` `.btn` `.chip` `.segment` `.search` `.navbar` `.action-bar` `.page-container` `.bg-dots`）以及全部 SVG 图标类。
- `miniprogram/custom-tab-bar/index.wxss` — 悬浮圆角玻璃导航栏样式及四个主入口图标（home/study/quiz/mine）默认/选中态。
- `miniprogram/app.json` — 全局窗口配置（`navigationStyle: custom`、`tabBar.custom: true`、`style: v2`、`lazyCodeLoading`）。
- 各页面 `pages/<name>/<name>.wxss` — 复用全局 token 与基础类，仅补充业务级布局与状态样式。

## 3. 架构与约定
- **设计令牌集中管理**：所有颜色、阴影、字体、圆角变体在 `app.wxss` 的 `page` 伪类下以 `--xxx` 变量声明，页面直接 `var(--xxx)` 引用，保证主题一致性。
- **基础组件类分层**：
  - 容器/卡片：`.page-container`、`.card`、`.sketch`、`.statusbar`、`.navbar`、`.action-bar`、`.page-pad`。
  - 交互控件：`.btn`（含 `.ghost`、`.deep` 变体）、`.chip`（含 `.on`）、`.segment`（含 `.seg-item.on`）、`.search`。
  - 排版辅助：`.sec-title`、`.hl`（荧光笔高亮）、`.icon`（统一 44rpx 图标占位）。
- **SVG 图标命名规范**：`ic-<场景>-<语义>`，如 `ic-back`、`ic-check-circle`、`ic-microscope`、`ic-fish`；选中态通过父级 `.tab.on .ic-xxx` 覆盖 data URI 中的 stroke 颜色。
- **手绘圆角变体**：`--r1` / `--r2` / `--r3` 使用四段 border-radius 模拟手绘不规则边框，配合 `border: 4rpx solid var(--line)` 和 `box-shadow` 强化纸感。
- **响应式策略**：全项目使用 `rpx` 单位，依赖小程序自适应；未引入媒体查询，布局以 Flex/Grid 为主，通过 `env(safe-area-inset-bottom)` 适配刘海屏。
- **动效约定**：点击反馈统一用 `transform: translate(4~6rpx, 4~6rpx)` + 阴影变化；TabBar 滑块使用 `cubic-bezier(0.34, 1.56, 0.64, 1)` 弹性曲线；骨架屏使用 `skeleton-pulse` 渐变扫描动画。

## 4. 开发者应遵循的规则
1. **新增颜色/阴影/字体必须走全局变量**：在 `app.wxss` 的 `page` 块中追加 `--xxx`，禁止在页面文件中硬编码色值。
2. **优先复用基础组件类**：按钮用 `.btn`，卡片用 `.card`/`.sketch`，分段控件用 `.segment`，搜索框用 `.search`，避免重复写相同样式。
3. **图标统一使用 `.icon` + `ic-xxx` 类**：不要自行设置宽高，保持 44rpx 标准尺寸；新增图标在 `app.wxss` 末尾按语义分组追加。
4. **手绘风格约束**：边框统一 `4rpx solid var(--line)`，圆角优先使用 `--r1/--r2/--r3` 或 `32~44rpx` 范围，阴影使用 `--sh` / `--sh-sm` / `--sh-green`。
5. **TabBar 扩展需同步更新**：新增 tab 项时，在 `custom-tab-bar/index.wxss` 中补充默认/选中态图标 data URI，并在 `app.json` 的 `tabBar.list` 中注册。
6. **页面结构模板**：外层包裹 `.page-container`，内容区使用 `.page-pad` 提供底部留白，顶部标题用 `.navbar`，操作区用 `.action-bar`。
7. **禁用全局样式污染**：页面 `.wxss` 只写业务相关选择器，不覆盖 `page`、`view`、`text` 等标签级样式。
