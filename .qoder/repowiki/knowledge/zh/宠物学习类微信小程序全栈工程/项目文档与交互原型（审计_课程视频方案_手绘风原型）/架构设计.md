本模块为纯文档与静态资源目录，按用途分为三层：
- `docs/check.md`：2026-07-17 三方联合审计的完整报告，按 P0/P1/P2/P3 分级列出阻塞项、数据库集合权限建议、性能分析与上线必做清单，是项目上线决策的唯一依据。
- `docs/courselist.md` + `docs/superpowers/specs/...` + `docs/superpowers/plans/...`：围绕「课程视频播放与考点双向跳转」这一特性，形成「数据清单 → 设计文档 → 可执行任务计划」的三段式推进链，plan 通过 `- [ ]` 子任务驱动 agentic worker 分步落地。
- `prototype/index.html`：单文件手绘线条风高保真原型，内嵌 CSS 变量体系与设计令牌，以四宫格手机模型展示首页/猫咪养成/知识地图/刷题四大留存策略，作为 UI 变更先行的确认入口；配套 `_preview*.png` 截图归档。
