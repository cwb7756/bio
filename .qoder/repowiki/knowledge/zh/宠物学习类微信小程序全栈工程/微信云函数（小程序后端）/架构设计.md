模块采用「一目录一云函数」的扁平结构：每个子目录（login、home、aiChat、flashcards、quiz、mistakes、achievements、settings、report、pet、knowledgeMap、getCourseList、getCourseDetail）都是一个独立的 Node.js 云函数，由各自的 `index.js` 作为入口并通过 `exports.main` 暴露；`config.json` 声明运行时（Nodejs18.15）、超时与 OpenAPI 权限，`package.json` 仅依赖 `wx-server-sdk`（部分含 bcryptjs）。

- 统一身份隔离：所有云函数通过 `cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV })` 初始化后，使用 `cloud.getWXContext().OPENID` 获取当前用户标识，并以 `_openid` 字段过滤数据库查询，实现多租户数据隔离。
- 统一路由分发：每个云函数的 `exports.main` 接收 `{ action, ... }` 事件，内部用 `switch(action)` 分派到同名异步处理函数（如 `wxLogin`、`emailLogin`、`updateProfile`），默认返回未知操作错误。
- 统一参数校验：每个函数顶部定义 `validateParams(obj)`，限制字符串长度 ≤ 10000、数组长度 ≤ 100，不合法直接返回 `{ code: 400, msg }`。
- 统一响应格式：成功返回 `{ code: 0, data|user|sessions|... }`，失败返回 `{ code: -1|400|404, msg }`，并在顶层 try/catch 中捕获异常并转为友好提示。
- 数据层：全部基于 `wx-server-sdk` 的 `cloud.database()` 直接操作云数据库集合（users、courses、lessons、study_progress、ai_chat_sessions、quiz_questions 等），无 ORM 或中间服务；部分函数（如 home）使用 `Promise.all` 并行聚合多个集合数据后再组装返回。
- 特殊能力：aiChat 还内置 RAG 上下文匹配（matchContext）与工具调用路由（toolQuery → search_courses_lessons / query_progress / query_mistakes / get_quiz / generate_quiz），供大模型 Function Calling 使用。
