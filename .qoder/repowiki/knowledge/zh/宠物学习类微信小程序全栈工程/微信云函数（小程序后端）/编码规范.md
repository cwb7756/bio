- 云函数入口统一为 `exports.main = async (event, context) => { ... }`，内部通过 `switch(event.action)` 分派到具体处理函数。
- 每个云函数首行调用 `cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV })` 并使用 `cloud.getWXContext().OPENID` 做用户身份绑定，所有写/读操作均以 `_openid` 过滤。
- 每个云函数内置 `validateParams(obj)` 校验器，拒绝超长字符串（>10000）和过长数组（>100），并返回 `{ code: 400, msg }`。
- 对外响应统一遵循 `{ code: 0, data }` 成功 / `{ code: -1|400|404, msg }` 失败的约定，并在顶层 try/catch 中将异常转为错误消息。
- 敏感字段通过专用转换函数（如 login 中的 `toSafe`）剥离 passwordHash、_id 等内部字段后再返回给客户端。
