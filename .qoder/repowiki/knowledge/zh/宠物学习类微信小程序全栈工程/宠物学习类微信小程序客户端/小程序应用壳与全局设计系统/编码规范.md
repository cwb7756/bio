- 全局状态集中在 `App().globalData` 中维护（如 `env`、`userInfo`、`isLoggedIn`），并通过 `getApp()` 在业务页读取或调用 `checkLogin()` 做登录拦截。
- CSS 采用「设计令牌」模式：在 `page` 伪类下用 `--xxx` 变量统一定义颜色、阴影、圆角变体与字体族，组件类直接消费这些变量而非写死值。
- 通用 UI 组件以单 class 名形式提供（`.sketch`、`.card`、`.btn`、`.chip`、`.segment`、`.search`、`.navbar` 等），业务页通过组合这些 class 拼装界面，避免重复样式。
- 图标系统以 `.ic-*` 命名约定组织，按功能域注释分组（导航类/操作类/角色类/科学类/菜单成就类/猫咪养成类/登录专用），全部使用内联 SVG data URI 作为 `background-image`。
- TabBar 与页面路由均在 `app.json` 中以数组形式集中声明，新增页面只需追加路径即可被框架识别。
