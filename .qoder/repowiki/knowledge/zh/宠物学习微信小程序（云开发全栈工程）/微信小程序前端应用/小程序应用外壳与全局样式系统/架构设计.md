本模块由四个顶层文件组成，承担小程序启动期与全局层职责：
- `app.js`：通过 `App()` 注册应用实例，在 `onLaunch` 中完成两件事——调用 `wx.cloud.init` 初始化云开发（环境 ID 硬编码为 `bio-d9gzmnqrif819033f`），并从 `wx.getStorageSync('userInfo')` 恢复本地登录态到 `globalData.isLoggedIn`；暴露 `checkLogin()` 供业务页统一拦截未登录跳转 `/pages/login/login`。
- `app.json`：声明所有页面路由（home/study/course/ai/mine/knowledge/quiz/profile/flashcards/mistakes/report/achievements/settings/pet/map）、自定义 TabBar（4 个 tab：首页/学习/AI答疑/我的，`custom: true`）、全局窗口主题（`navigationStyle: custom`）及性能开关 `lazyCodeLoading: requiredComponents`，并通过 `sitemapLocation` 引用 `sitemap.json`。
- `app.wxss`：集中定义 CSS 变量作为「设计令牌」（颜色、阴影、圆角变体、字体族），并提供一套可复用的手绘风格通用组件类（`.sketch`、`.card`、`.btn`、`.chip`、`.segment`、`.search`、`.statusbar`、`.navbar`、`.action-bar`、`.page-container` 等），以及按语义分组的 SVG 线性图标类（导航/操作/角色/科学/成就/猫咪养成/登录专用），全部以内联 data URI 的 SVG 作为背景图，避免额外资源请求。
- `sitemap.json`：通过 `disallow: "*"` 规则禁止搜索引擎收录小程序页面。
依赖方向单向向下：仅依赖微信基础 API（`wx.*`），不引入任何第三方包；业务页面通过 `getApp().globalData` 和 `getApp().checkLogin()` 消费此壳提供的能力。
